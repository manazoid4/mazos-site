# Maz Works playbooks

Five short guides so any agent (Codex, Gemini, Hermes, another Claude) can keep the same quality while Claude is unavailable. Read `AGENTS.md` first, then the playbook for your job.

| # | Playbook | Use it when |
|---|----------|-------------|
| 1 | [Ship a site change](1-ship-a-site-change.md) | any code or copy change |
| 2 | [Offer, prices and voice](2-offer-prices-and-voice.md) | touching prices, packages, words on the site |
| 3 | [Design and pages](3-design-and-pages.md) | new page, component, colour, icon |
| 4 | [Forms and conversion](4-forms-and-conversion.md) | forms, funnels, LinkedIn link-ups, tracking |
| 5 | [Leads and outreach](5-leads-and-outreach.md) | finding leads, messages, HubSpot |

Golden rules (all five):
- Branch + PR, never push to main.
- Never invent clients, results or testimonials.
- Never publish Maz's location, personal email or phone. The public contact is info@mazworks.uk only.
- No AI in the offer.
- Proof before "done": command output, test result, screenshot or live URL.
- End every reply with a one-paragraph plain-words summary and Maz's open to-dos.
